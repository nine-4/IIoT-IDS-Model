
# IIoT-IDS-Model

This project involves building an Industrial Internet of Things (IIoT) Intrusion Detection System (IDS) model.

## Setup Instructions

### 1. Create and activate a virtual environment

To ensure that all dependencies are managed and isolated, create a virtual environment using the following commands:

```bash
python -m venv sklearn-env
```

Activate the virtual environment:

- On Windows:

```bash
.\sklearn-env\Scripts\activate
```

### 2. Install dependencies

Once the virtual environment is activated, install the necessary dependencies with the following command:

```bash
pip install -U scikit-learn
```

### 3. Running the Model

After setting up the virtual environment and installing the dependencies, you can run the file.

### 4. Testing and Comparison

A batch file has been created for testing and comparison purposes. You can use it to automate some of the testing and execution processes.

```bash
.\test.bat
```

## Reminder

Make sure to activate the virtual environment first by running:

```bash
.\sklearn-env\Scripts\activate
```

Then proceed to run the necessary files as described above.
